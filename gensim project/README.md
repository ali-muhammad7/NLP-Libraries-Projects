# Gensim Star Chart

A beginner-friendly NLP visualization tool built with Python, Tkinter, and Gensim. It transforms text into an interactive star chart to explore word frequency, topics, and word similarities.

## Features
- Visualizes frequent words as stars.
- Groups words using LDA topic modeling.
- Finds similar words using Word2Vec.
- Displays sentence similarity.
- Interactive GUI for exploring text.

## Technologies
- Python
- Gensim
- Tkinter
- Word2Vec
- LDA

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Purpose
This project demonstrates how Gensim can be used for word embeddings, topic modeling, and text analysis.
