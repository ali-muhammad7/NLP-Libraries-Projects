# NLP Libraries & Projects

A collection of hands-on Python projects exploring popular Natural Language Processing (NLP) libraries and frameworks.

## About This Repository

This repository contains practical experiments and projects built while learning different NLP tools, techniques, and frameworks.

The goal is to understand how different libraries work and explore their applications in Natural Language Processing.

## Libraries Covered

| Library | Focus |
|---|---|
| NLTK | Text processing and tokenization |
| spaCy | Industrial NLP and linguistic analysis |
| TextBlob | Sentiment analysis and text processing |
| VADER | Sentiment analysis |
| Gensim | Topic modeling and word embeddings |
| Hugging Face | Transformers and pretrained models |
| Flair | NLP models and embeddings |
| Stanza | Linguistic analysis |
| Textacy | Advanced text processing |
| PyNLPl | NLP utilities |
| KerasNLP | Deep learning for NLP |
| PyTorch NLP | NLP with PyTorch |
| Polyglot | Multilingual NLP |
| FastTrack | NLP experiments |

4. Run the Python scripts.
