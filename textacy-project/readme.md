# Textacy Text Insights

A beginner-friendly NLP desktop application built with Python, Tkinter, spaCy, and Textacy. It provides useful text analysis tools through a dark analytics dashboard.

## Features
- **Key Terms:** Extract important words and phrases using TextRank.
- **Readability:** Calculate Flesch Reading Ease and Flesch-Kincaid Grade Level.
- **N-Grams:** Extract bigrams and trigrams.
- **Basic Statistics:** Analyze word count, unique words, sentences, characters, and syllables.
- Interactive dashboard with metric cards and score visualization.

## Technologies
- Python
- Textacy
- spaCy
- Tkinter

## Installation

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

## Run

```bash
python main.py
```
