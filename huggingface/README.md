# Prismatic Transformer – The Crystal Mind

An interactive educational GUI that visually demonstrates important Transformer and NLP concepts using Python and Tkinter.

## Features
- Token visualization and inspection.
- Embedding prism visualization.
- Simulated attention weights.
- Transformation layer visualization.
- Demo predictions for different NLP tasks.

## Technologies
- Python
- Tkinter

## Installation

No external packages are required. Tkinter is included with most standard Python installations.

## Run

```bash
python main.py
```

## Note
This project is an educational simulation. It does not use a real Transformer model or perform actual model inference.
