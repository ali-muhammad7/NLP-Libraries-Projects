# FastText Genome Lab

An interactive web-based visualization project that explains how FastText uses character n-grams to represent words and handle unknown or misspelled words.

## Features
- Character n-gram extraction (3–6 characters)
- Word vector generation demonstration
- Similar word discovery
- Word similarity comparison using cosine similarity
- DNA helix and gene fragment visualization
- Genetic fingerprint visualization
- Unknown word demonstration

## Technologies
- HTML
- CSS
- JavaScript
- SVG

## How to Run
1. Open the project folder.
2. Open `index.html` in your web browser.
3. Enter a word and explore the available features.
