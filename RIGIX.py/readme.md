# RegexLab – Pattern Matcher

A simple Python GUI application for testing Regular Expressions (Regex). It allows users to search for patterns in text and view matching results.

## Features
- Find matches using custom regex patterns.
- Quick patterns for Email, Phone, URL, and Digits.
- Display all matches with their total count.
- Handle invalid regular expressions.
- Clear input and results easily.

## Technologies
- Python
- Tkinter
- `re` (Regular Expression Module)

## Installation

No external packages required.

## Run

```bash
python main.py
```

## Purpose
This project demonstrates how Regular Expressions can be used for pattern matching and text searching.
