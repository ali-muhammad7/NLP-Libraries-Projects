# TextBlob Text Analyzer

A beginner-friendly NLP desktop application built with Python, Tkinter, and TextBlob. It analyzes text through a simple notebook-style interface.

## Features
- Sentiment analysis with positive, negative, and neutral results.
- Display sentiment polarity and subjectivity scores.
- Visual mood meter.
- Extract noun phrases.
- Perform Part-of-Speech (POS) tagging.
- Calculate basic text statistics.
- Correct spelling mistakes.

## Technologies
- Python
- TextBlob
- Tkinter

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
