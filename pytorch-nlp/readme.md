# Neural Theatre – Where Every Word Takes a Role

An interactive educational NLP visualization built with Python and Tkinter. It presents words as performers on a virtual theatre stage to demonstrate basic NLP concepts.

## Features
- Visualize text tokens as animated performers.
- Explore token roles and categories.
- View simulated embeddings and activation values.
- Demonstrate sentiment classification.
- Show demo Named Entity Recognition (NER).
- Display simulated text generation.
- Interactive stage with animations and token selection.

## Technologies
- Python
- Tkinter
- Tkinter Canvas
- Python Standard Library

## Installation

No external packages required.

## Run

```bash
python main.py
```
