# Neural Bloom – Keras NLP

An interactive visual demonstration of NLP and neural network concepts, built with Python and Tkinter.

## Features
- Text tokenization visualization.
- Word embedding demonstrations.
- Neural layer and activation visualization.
- Demo sentiment and text classification.
- Interactive NLP prediction interface.

## Technologies
- Python
- Tkinter

## Installation

No external packages are required. Tkinter is included with most standard Python installations.

## Run

```bash
python main.py
```

## Note
This is a visual educational demo, not an actual Keras or TensorFlow implementation. Predictions and neural network visualizations are simulated.
