Polyglot – The Living Language Globe

An interactive Python application that visualizes languages on a rotating 3D-style globe using Tkinter.

Features

Animated rotating Earth visualization.

Demo language detection from text.

Highlights associated linguistic regions.

Displays language information, native scripts, and language families.

Supports 14 sample languages, including Urdu, English, Arabic, Hindi, and Japanese.

Technologies

Python

Tkinter

Canvas

Python Standard Library

Installation

No external packages required.

Run

Author: Ali Muhammad
python main.py
