# Flair – NLP Signal Command Center

An interactive NLP visualization application built with Python and Tkinter. It demonstrates token analysis, linguistic classification, and named entity detection through a modern command-center dashboard.

## Features
- Tokenization and linguistic analysis
- Part-of-Speech (POS) tagging demonstration
- Lemma extraction
- Named Entity Recognition (NER) demonstration
- Token classification with confidence scores
- Interactive context signal map
- Animated signal waveform and analysis dashboard

## Technologies
- Python
- Tkinter
- Python Standard Library

## Installation
No external packages required.

## Run
```bash
python main.py
```

## Note
This is an educational simulation, not an actual Flair NLP implementation. It uses predefined sample data and rule-based logic rather than a trained machine learning model. Confidence scores are simulated.
